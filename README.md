# 实验二：三维海豚与几何变换（精简版）

## 打开

**直接双击`index.html`，用Edge或Chrome打开即可。**

只需要`index.html`、`style.css`、`app.js`、`js/`和`assets/`文件夹放在同一目录，无需安装依赖、运行服务器或连接网络。也可以用VS Code Live Server打开。

## 这版改了什么

- 参照`参考.zip`的规模：工具栏、画布、状态、操作按钮。删除旧版品牌、标语、侧边面板、卡片和复杂CSS。
- 模型改为真正的三维低多边形海豚；吻部为+Z前进方向，背鳍为上，左右胸鳍与尾鳍便于观察旋转。
- 普通defer脚本代替ES Modules，可以直接以file://打开。旧版以file://打开时确实复现停留初始化，但不能据此认定此前所有设备上的失败都属于同一原因。
- 保留A/B/C、坐标轴与轨迹、ASCII/二进制STL导入，并支持随STL保存的逐面颜色。辅助功能统一放在一个默认折叠区。
- 主程序拆分为`js/`下8个普通脚本（数学、渲染、相机、输入、STL、UI、导入流程、页面控制器），`app.js`只保留启动入口与Node导出；不需要打包构建。
- 海豚模型不再内置在JS中：页面启动后由用户手动导入`assets/海豚_ASCII.stl`或`assets/海豚_Binary.stl`（852个三角形，含6种颜色）。
- 删除“恢复海豚”和“对比T·R / R·T”功能，界面只保留模型变换、观察和辅助显示。

## 操作

| 场景 | 操作 |
|---|---|
| 加载模型 | 展开“辅助显示与STL”，选择`assets/海豚_ASCII.stl`或`海豚_Binary.stl` |
| 物体坐标 | W/S前后；A/D转向；I/K俯仰；Q/E翻滚 |
| 屏幕坐标 | 方向键平移；I/K绕屏幕X；A/D绕屏幕Y；Q/E绕屏幕Z |
| 观察相机 | 鼠标左键拖动Arcball；滚轮缩放；观察菜单选择正/侧/背/顶或定位模型 |
| 重置 | R或“重置模型”只恢复模型；“恢复视角”只恢复相机 |
| 停止 | 松开按键或按钮即停止；窗口失焦自动清理输入 |
| 按钮 | 画布下方按钮与键盘相同，支持按住连续动作 |
| 辅助功能 | 展开“辅助显示与STL”即可操作 |

选择模式或观察视角后会将焦点移回画布，可以直接按键。编辑文件选择框时键盘优先交给控件。模型移远时，观察菜单选“定位模型”，或重置模型并恢复视角。

## 数学约定

右手系，世界+Y向上；局部+Z为海豚吻部前向。Yaw绕局部Y，Pitch绕局部X，Roll绕局部Z；正方向遵循右手法则，所以正Pitch使头部向下。

列向量、矩阵列主序，`p_clip=P·V·M·p_local`，`M=T·R·S`，右侧先作用。四元数为`[x,y,z,w]`，局部旋转右乘，转换到世界空间的屏幕轴旋转左乘。

## 测试

需要复验时使用Node.js 22或更新版本，无需安装npm包：

```powershell
node --test tests/core.test.mjs
node tests/browser.mjs
```

第二条需要Windows安装Edge，会启动独立测试浏览器，不使用个人浏览器资料。`EDGE_PATH`可指定Edge路径；`DOLPHIN_TEST_URL`可指定另一份页面的file/HTTP地址。

2026-10-27实际通过10项单元测试、16项Edge浏览器场景，包含直接file打开、HTTP打开、手动导入带颜色海豚STL、三维绘制、A/B/C、按键释放、模式焦点、轨迹、两种STL、逐面颜色和窗口适配。结果在tests目录。浏览器使用SwiftShader软件WebGL，不代表所有设备的硬件帧率。

## 限制

- 运动是几何实验，没有物理碰撞或重力；网格只是参考平面。位置各轴限制±40，轨迹最多3000点。
- STL上限20 MiB/200000面，拒绝非法顶点、退化面、缺损结构和非标准二进制尾数据。无颜色模型统一显示为蓝色，局部+Z仍约定为前向。
- STL颜色是扩展：二进制使用VisCAM/SolidView属性字节，ASCII在facet内写入`color r g b`行（0..1）。普通STL软件可能忽略颜色，但本页导入时会保留。
- 世界轴和局部轴为教学清晰度置顶显示；海豚本身启用深度测试。
- 没有实时阴影贴图、骨骼动画或外部3D框架。所有面片均由WebGL实际绘制。
